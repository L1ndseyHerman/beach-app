# Beach App -- STILL IN PROGRESS!!

ReadMe in-progress too.

Run Locally:
yarn dev

Send it to the master branch:
Normal Git committing stuff

Send it to the gh-pages branch that makes it live on GitHub pages:
yarn build
yarn deploy

Note that you have to go to the url currently. For example, "/beach" can be found at

http://localhost:5173/beach-app/#/beach

or

https://l1ndseyherman.github.io/beach-app/#/beach

. Eventually, I want to make a login page that redirects there, but that won't be for awhile.

yarn test

also works now.

Also

npx cypress open.
